## Guide pour Thomas

- **Les blocs disent « Nom · lieu »** : « Computer Network Lab · 2F51 ». Quand la place manque, le lieu est coupé avant le titre. Un cours en plusieurs salles affiche « 2F51, 2E51… » ; la liste complète est dans l'aperçu et dans la fiche.
- **Tes vieux codes de cours deviennent des noms** : Réglages › Agenda › Sources › **« Recalculer les titres »**.
  - L'aperçu montre les nouveaux titres. Un titre que tu as changé toi-même est décoché.
  - Rien n'est écrit avant **« Appliquer »** ; une sauvegarde est faite avant, et « Annuler » reste possible ensuite.
  - Un bandeau dans l'Agenda te le propose quand c'est utile. Fermé, il ne revient pas tant que rien ne change.
- **Souris posée sur un cours (PC)** : une petite carte apparaît après un court instant. Elle donne le titre complet, les heures, le lieu complet, la catégorie, la note (groupe, enseignants), le code du cours et l'horaire d'où il vient. Elle part quand tu bouges, cliques, fais défiler ou appuies sur Échap.
- **Clic sur un bloc (PC)** : la fiche s'ouvre **à droite**, sans remonter la page. Pour la fermer : le bouton de fermeture, Échap, ou un clic sur la page.
- **Témoin de synchro du PC** : en bas de la barre latérale, sous « Réglages ». Il dit « Synchro arrêtée », « En attente du téléphone », « Synchronisé · il y a 5 min » ou « Synchro bloquée », avec la raison au survol. Un clic ouvre la page de synchro.
- **Réglages › Synchro › « Réseaux et adresses »** (et le même onglet sur le téléphone) :
  - le réseau actuel du PC et son type Windows. S'il est **Public**, la page te dit quoi faire ; ToolBox ne change jamais ce réglage lui-même ;
  - les réseaux où le téléphone a déjà essayé de se synchroniser. Tu peux les nommer (« Kot », « Maison ») ou les oublier, avec « Annuler » ;
  - les 50 derniers essais.

- **Le dernier échec bloque le témoin** jusqu'à la synchro réussie suivante, même si la cause a disparu entre-temps. C'est voulu (le dernier état connu), mais à savoir.
