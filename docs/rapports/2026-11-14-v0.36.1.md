### Sécurité et fiabilité (`3bf6651`, `7663cd5`)

- **Socle PC**, inchangé depuis v0.14.1 et conforme : jeton comparé en temps constant, Host et Origin vérifiés, `Sec-Fetch-Site: cross-site` refusé, tickets SSE à usage unique (30 s), médias signés, `safeJoin`.
- **Synchro** :
  - écouteur désactivé par défaut, vraiment fermé (`app.close()`, sockets terminés, mDNS retiré) ;
  - jeton d'appareil : seul son SHA-256 est gardé ;
  - code d'appairage à usage unique (10 min, 5 essais) ;
  - certificat épinglé dans le `TrustManager` : refus pendant la poignée de main, avant tout envoi (le nom d'hôte n'est pas vérifié, volontairement : l'adresse change, le certificat est épinglé à l'octet) ;
  - mDNS seulement pendant l'écoute ;
  - tables et colonnes vérifiées avant toute écriture, application en une transaction ;
  - noms de fichiers des photos filtrés (`SAFE_NAME`, sha256, jamais un chemin reçu) ;
  - lot limité à 64 Mo ;
  - WebSocket fermé à « Oublier ».

  Tout est couvert par des tests ; le lot forgé l'est désormais aussi.

- **Téléphone** : `allowBackup="false"` (voir B3), CSP stricte (`default-src 'self'`), aucun appel réseau dans la page (seulement par les greffons épinglés).
- **Dépôt public** : aucun secret trouvé (motifs de clés Google, GitHub, clés privées, mots de passe). Workflows :
  - secrets passés par l'environnement, jamais affichés ;
  - fichier de clé en `umask 077` puis supprimé ;
  - mot de passe masqué (`::add-mask::`) dans `android-keystore.yml` (lu, **pas relancé**).
- **Fiabilité** :
  - écouteurs `window`/`document` : tous posés une seule fois pour la vie de l'appli (gardes vérifiées) ;
  - intervalles : tous libérés ;
  - processus (FFmpeg, ffprobe, whisper, Piper) : tués à l'annulation et à l'arrêt ; seul Ollama reste ouvert volontairement ;
  - batch des Courses et synchro : en transactions.
- **Erreurs avalées** : aucun `catch {}` vide. 31 `.catch(() => undefined)` et 83 blocs `catch` sans journal, tous relus. Ce sont des valeurs par défaut quand une lecture échoue, un réglage local non retenu ou une fonction facultative absente. **Aucun ne masque l'échec d'une écriture de données** : rien à corriger.
