## 2. Ce qui a été fait

  - **Documentation** : `docs/MODULES.md` §7.1.
  - **Captures** : `docs/rapports/captures-v0.14.2/listes-avant-apres.png`.
- **Tests en deux niveaux (`0eb6151`)** :
  - **`fullRenderTests`** (`@hub/sdk/testing`) ne vaut vrai qu'avec `vitest run --mode full` (`npm run test:full`) ; un seul fichier de config (`vitest.config.ts`), compatible Windows.

  - **Restés rapides** : les aperçus, les petits rendus et la synchro.
  - Le test « pas de styles de Reel » ne lit que la base. Il a été remonté avant le rendu pour rester dans les tests rapides.
  - **CI** : `npm run test:full` au lieu de `npm test`.
  - **Règle ajoutée** dans CLAUDE.md (Commandes, Conventions, Hygiène), ainsi que dans `MODULES.md` §8 et `AJOUTER-UN-MODULE.md`.

## 4. Décisions prises sans Thomas

- **Le composant prend toute la mise en page** (liste + panneau), pas seulement la liste : la grille et le panneau étaient eux aussi recopiés trois fois.
- **Arrondi des lignes pris dans le thème** (`--radius-sm`, 10 px dans Nebula) plutôt que les 8 px écrits en dur dans deux pages sur trois. C'est la convention « arrondis = variables du thème ». Pour revenir à 8 px : `.ui-tracks__item` dans `styles.css`.
- **Tests rapprochés de leur rendu** : les tests qui dépendent des fichiers d'un rendu complet passent dans la suite complète. Sinon, il aurait fallu les réécrire avec de faux fichiers, ce qui aurait changé ce qu'ils vérifient.
- **Tests du moteur à 2–4 s laissés dans la suite rapide** : petits rendus (extrait, fondus, post, miniature), qui gardent le moteur testé à chaque session.

## 6. Bugs trouvés

- Dans la liste de Vidéo YouTube et du Pack Insta, le « ♪ » de la vignette sans cover était collé en haut. Une règle CSS trop large lui donnait une mise en page en colonne. Il est maintenant centré.

## 9. Risques et points à surveiller

- **Suite rapide** : elle ne fait plus de rendu complet. Une régression de rendu ne se verra qu'en CI, ou avec `npm run test:full`, que la règle de CLAUDE.md impose dès qu'un rendu est modifié.
- **Durée de la CI** : la CI lançait déjà tous les tests, donc la durée est inchangée.
- **Nouveau test de rendu complet** : il doit être marqué `fullRenderTests`, sinon il ralentit la suite rapide. C'est documenté dans `MODULES.md` §8.
