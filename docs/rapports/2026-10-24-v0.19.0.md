### Partie 2 — Corrections ciblées

- **Écoute A/B** (`4f9db62`, `master-analysis/frontend/References.tsx`, `shared/measures.ts` `abLevels`) :
  - la plus forte des deux est baissée par le volume du lecteur (≤ 1) ; le volume n'est jamais monté ;
  - l'ancien gain Web Audio (qui pouvait monter la référence) est retiré ;
  - la ligne sous les boutons dit laquelle est baissée et de combien (ex. « Master baissé de 0,8 dB à l'écoute ») ;

- **Sauvegardes** (`fdebcd4`, `backend/core/backups.ts`, `hub.ts`, `routes/core.ts`, Réglages) :
  - deux rotations de 10 :
    - avant migration (`hub-<date>-avant-<module>-v<n>.db`) ;

  - chacune n'efface que les siennes ;
  - les fichiers déjà présents sont classés d'après leur nom ;
  - Réglages › Sauvegardes montre les deux listes et le nombre gardé pour chacune ;
  - test : 25 suppressions n'effacent aucune sauvegarde d'avant migration.
- **Reels perso** (`30306ed`, `custom-reels/backend/index.ts`, `packages/sdk/components.tsx`) :
  - la vérification rapide ne regarde que les Reels qui vont être rendus, avec leur mode de son ;

## 9. Risques et points à surveiller

- **Le guide peut vieillir** : à chaque changement d'interface de l'Analyse du master, il faut mettre à jour le texte et relancer `scripts/guide-captures.mjs`. Le test ne voit qu'un « ? » ou un repère cassé, pas une phrase devenue fausse.
- Captures prises dans le **thème par défaut** : avec un autre thème, les couleurs des captures diffèrent de l'écran.
- `scripts/guide-captures.mjs` suppose Playwright installé (c'est le cas dans l'environnement cloud, pas dans le projet).
